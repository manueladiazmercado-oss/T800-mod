# T-800 HUD — Fabric 1.21.11

Client-side Terminator-style HUD and tactical analysis mod for Minecraft 1.21.11 (Java 21, Fabric Loader + Fabric API).

## Features
- Target lock, live target data, threat ranking and combat analytics
- Persistent local Target Dossiers keyed by player UUID, unlimited profile count, sightings and observed combat statistics; target acquisition requires a stable 400 ms lock to avoid creating dossiers during quick lobby mouse sweeps (P)
- Combat Replay records sampled local movement/rotation/health/distance telemetry to per-fight CSV files and provides a top-down playback reconstruction via OPEN REPLAY
- Tactical movement-pattern estimates, combat memory and incoming-projectile forecast
- GigaMap with block-scale zoom, sampled height relief, loaded-entity markers and persistent bookmarks
- Thermal vision, survival telemetry, armor integrity alerts and custom HUD effect glyphs
- Flight Assist while using Elytra: forward-path collision sampling and obstacle-distance warnings
- Optional push-to-talk assistant using Whisper.cpp for transcription, the mod's local tactical analysis for answers, and operating-system speech synthesis
- Bundled T-800 HUD, food, Elytra, crossbow and 3D-weapon resource packs

## Keybinds
- H: HUD on/off
- J: cycle target mode
- K: Terminator vision
- I: thermal vision
- F4: Combat Analytics overlay
- P: Target Dossier / Combat Replay
- In the dossier screen: OPEN REPLAY to play back the latest recorded fight for the selected player
- F6: GigaMap
- F7: PvP profile
- F8: Termination mode
- F9: performance profile
- F10 (hold): voice assistant
- F11: confirm proposed assistant action
- F12: cancel proposed assistant action
- Right Shift: settings

## Where the textures are generated
The packs are generated by Gradle during the build, then bundled inside the JAR under `resourcepacks/`:
- **Elytra texture:** `build/generated/t800ElytraPack/resourcepacks/t800_elytra/assets/minecraft/textures/entity/elytra.png`
- **3D weapon models and their textures:** `build/generated/t800GearPack/resourcepacks/t800_arsenal/assets/minecraft/models/item/` and `.../textures/item/`
- **Animated plasma crossbow:** `build/generated/t800CrossbowPack/resourcepacks/t800_crossbow/assets/minecraft/textures/item/`
- **HUD sprites:** `resources/resourcepacks/t800_gui/assets/minecraft/textures/gui/sprites/`
- **Texture generation source:** `build.gradle` (tasks `generateT800ElytraPack`, `generateT800GearPack`, and `generateT800CrossbowPack`)

The bundled Elytra and Arsenal packs are registered as built-in packs. If the skin does not appear, open **Options → Resource Packs**, make sure **T-800 Cybernetic Elytra** and **T-800 Arsenal Weapons and Armor** are enabled, then reload resource packs with F3+T. The Elytra keeps Minecraft's vanilla 3D wing geometry; this is a texture replacement, not a custom animated wing model. The flight HUD appears only while gliding with an Elytra; pressing F5 only changes the camera perspective.

## Build
GitHub Actions builds the JAR using Java 21 and Gradle. Open the repository's **Actions** tab, select the latest successful **build** run, and download the `t800hud-jar` artifact. The artifact is a build output, not proof of in-game testing.

## Voice assistant
The assistant does **not** connect to Ollama or another language model. Whisper.cpp is used only for speech-to-text; answers are composed from the mod's local combat analysis, target data, status effects, threats and coordinates. Speech output uses the installed operating-system TTS voice. Speech recognition requires `whisper-cli` and a model file at `config/t800hud/ggml-base.bin`.
